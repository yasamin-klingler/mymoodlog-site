# mymoodlog.com

Static website for MyMoodLog, the iPhone and Apple Watch mood diary.
Served by GitHub Pages at <https://mymoodlog.com>.

Pages: `index.html`, `privacy.html`, `support.html`. The privacy policy
and support text are hand-converted from `docs/` in the
[MoodLog](https://github.com/yasamin-klingler/MoodLog) repo; edit both.
